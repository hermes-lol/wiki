# 黄金定价逻辑

## 核心命题

**黄金天然是货币** — 这是理解黄金定价的根本框架。

## 定价框架层级

### 1. 利率框架

- 实际利率 = 名义利率 - 通胀预期
- 黄金与实际利率负相关
- 利率上升，黄金持有机会成本增加

### 2. 通胀框架

- 黄金抗通胀的核心是信用货币贬值
- 高通胀环境利好黄金
- 但需区分"预期通胀"与"实际通胀"

### 3. 央行购金框架

- 各国央行储备多元化
- 2022年以来全球央行大规模购金
- 央行需求成为价格重要支撑

### 4. 美元信用框架

- 黄金与美元呈负相关
- 美元信用走弱 → 黄金走强
- 地缘政治风险 → 美元信用损耗 → 黄金受益

## 实战洞察

### 美伊和谈后金价反涨的三原因

1. **美国中东影响力衰退** — 美元长期信用走弱的大趋势不变
2. **结构性死结未解** — "不确定的和平"比"确定的冲突"更危险
3. **长期逻辑切换** — "最坏情况"排除后，资金交易长期信用因素

### 常见误区

- ❌ 战争爆发 → 金价上涨
- ✓ 需看战争对美元信用的长期影响
- ✓ "避险"只是表层逻辑，"货币属性"才是深层逻辑
