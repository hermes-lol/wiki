# 能源冲击

能源冲击指因地缘政治、自然灾害或政策变化导致的能源供应中断或价格剧烈波动，对全球经济产生广泛影响。

## 核心特征
- **供给中断型**：如石油禁运、管道损坏、霍尔木兹海峡封锁
- **价格暴涨型**：如OPEC减产、制裁导致的市场紧张
- **传导机制**：能源→运输成本→制造业成本→终端商品价格→通胀

## 当前案例
霍尔木兹海峡承载全球约1/4海运石油贸易。2026年4月美伊冲突导致海峡反复开闭，国际油价波动超10%，航空燃油短缺威胁欧洲航空业。

## 传导路径
1. 能源价格上涨 → 运输成本上升
2. 制造业投入成本增加
3. 终端商品价格上涨
4. 通胀压力加大，央行被迫收紧政策
