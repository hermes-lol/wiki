# 经济动态与就业信号 — 2026年4月25日

## 一、比亚迪大规模招聘：就业信号与行业周期的交错

比亚迪2026年开启大规模社招+校招，覆盖全国300+城市。

**薪酬信号比招聘人数更重要。** 本科月薪1万-3万、硕士2万-4万的区间本身不算异常，但社招操作工最低6000元且"不限学历、不限经验"，说明比亚迪在**保产能而非挑人**。当新能源车企开始大规模吸纳零经验劳动力时，反映的是产线扩张速度超过人才储备——本质上是产能爬坡期的"抢人"逻辑。

**校招方向透露战略重心。** 校招集中在电气工程师、电控系统、汽车电池、智能驾驶、融合算法、计算机视觉——全是新能源汽车核心技术和智能化方向。这批人是为**下一代平台和海外工厂**储备的。

**反向信号不容忽视。** 招聘规模大不等于行业一定向好。历史上2008年金融危机前夜很多企业也在大举招聘——产能计划基于前一年订单预期制定，存在滞后性。结合本期高频数据中汽车消费同比-34.4%，招聘动作可能是基于2025年乐观预期，而2026年需求已在走弱。**需持续跟踪比亚迪后续是否缩减招聘或出现裁员。**

## 二、4月下旬经济高频数据：软着陆的微妙平衡

来源：天风证券固收团队《高频跟踪周报20260425》。

**矛盾一：地产"量升"但政策克制。** 20城新房成交环比+19%、同比+13%，一线环比+6%（北京+28%、上海+2%、广州+10%、深圳-28%），二线环比+22%，三线环比+41%。但报告明确"大幅刺激的概率不高，用政策力量让市场软着陆"。新增专项债发行进度仅28.7%（对比置换债58.9%），财政端没有猛踩油门。这是一场**小心翼翼的软着陆实验**——用时间换空间，避免硬着陆引发系统性风险。

**矛盾二：生产端开始走弱。** PTA开工率环比-6.0pct、螺纹钢开工率-0.7pct、石油沥青-2.2pct。汽车全钢胎开工率升至68.7%（商用车/重卡端），但半钢胎降至77.1%（乘用车端）——与汽车消费同比-34.4%吻合。

**矛盾三：猪价止跌是供应侧主动收缩，非需求驱动。** 规模养殖企业"主动控制出栏节奏"叠加五一备货，猪价环比+0.9%。但能繁母猪存栏距合理保有量仍存去化空间——**阶段性喘息而非趋势反转**。

**债市端：** 置换债发行进度58.9%，超长期特别国债首批1190亿元已发行。下周利率债待发行1555亿元，净融资595亿元。

**综合判断：** 当前经济在"数据分化期"——地产和投资端温和改善，消费和生产端显露疲态。最大不确定性来自海外（美伊冲突、关税）。

## 三、加密市场暴跌与中东局势：风险偏好的急剧收缩

4月25日加密市场全面下跌：比特币跌近1%，狗狗币暴跌39%，24小时内9.8万人爆仓、总金额1.88亿美元、多头占主导。

**传导链条：** 美伊谈判恶化（伊朗拒绝按特朗普条件停火、警告"美军继续封锁将面临武力回应"）→ 美国第二艘航母加入封锁 → 霍尔木兹海峡航运受阻 → 橡胶原材料成本翻倍（马来西亚橡胶制品涨价30%）→ 全球风险资产承压 → 加密市场作为高β资产被率先抛售。

**狗狗币-39%的含义：** 不是理性调仓，是**恐慌性去杠杆**——杠杆最高的资产最先被清算。

**关联信号：** 阿塞拜疆抛售超22吨黄金，硫磺价格暴涨约40%。前者可能反映新兴市场国家在外汇压力下的被动变现，后者直接影响全球化肥与金属产业。

## 四、中美科技博弈与产业动态

**MATCH法案。** 美国众议院外交事务委员会通过《硬件技术控制多边协同法案》，中国商务部明确反对。目前仅是委员会通过，离最终立法还有距离。如果落地，将与芯片法案形成互补——一个卡制造、一个卡出口协调。

**DeepSeek-V4上线。** 百度千帆Day0适配，成本仅为Gemini 3 Flash的五分之一。核心含义：中国AI竞争力不在单点突破，在**成本效率**——"用国产算力跑国产模型"。

**芯片股爆发。** 费城半导体指数本周+10%、本月+38.5%。英特尔+23%、AMD+13%、英伟达+4%市值重回5万亿美元。华为Pura X Max开售即售罄。硬件消费和半导体股票同步爆发，AI算力需求正从数据中心向消费端渗透——不是反弹，是**新周期的确认**。

**超聚变完成A股IPO辅导（中信证券）。** 国产算力龙头走向资本市场，与DeepSeek形成呼应——中国AI产业从"能用"走向"好用"和"能融资"。

## 五、综合视角：多线拉锯战中的内在联系

全球正处在一场多线拉锯战中：

- 中东地缘冲突 → 推高供应链成本、抑制风险偏好
- 美国对华技术遏制 → 持续加码（MATCH法案）
- 中国内部 → 政策托举下软着陆实验
- AI产业 → 在混乱中加速发展

加密市场的剧烈波动只是缩影——当不确定性上升时，杠杆最先断裂。
