## 接入Claude Code步骤

### 第一步：获取API Key
前往火山方舟平台注册账号 → 开通模型服务 → 获取API Key

### 第二步：配置settings.json
```json
{
  "env": {
    "ANTHROPIC_API_KEY": "<你的火山API Key>",
    "ANTHROPIC_BASE_URL": "https://ark.cn-beijing.volces.com/api/v3"
  }
}
```

### 第三步：启动
```bash
claude --dangerously-skip-permissions
```
